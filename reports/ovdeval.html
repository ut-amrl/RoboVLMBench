OVDEval

Open-vocabulary detection with misleading descriptions: 15142 photos in 8 subsets, scored with the official NMS-AP evaluation.

What each subset tests

Each photo comes with a list of descriptions; the model boxes every object matching one and labels the box with it. Most descriptions are hard negatives that differ from a true one in a single detail, or names of people, logos or places not in the photo. One request per photo, with all of its descriptions.

  • Color (1170 photos, 6.5 descriptions per photo): an object's color. E.g. true: “red fruit”; also asked: “blue fruit”, “brown fruit”, “green fruit”, “white fruit”…
  • Material (2124 photos, 10.0 descriptions per photo): what an object is made of. E.g. true: “iron chair”; also asked: “bamboo chair”, “copper chair”, “enamel chair”, “glass chair”…
  • Position (2109 photos, 4.1 descriptions per photo): where an object is relative to another. E.g. true: “the scissors behind the silver scissors”; also asked: “the scissors in front of the silver scissors”, “the scissors on the left of the silver scissors”, “the scissors on the right of the silver scissors”
  • Relationship (2169 photos, 9.7 descriptions per photo): what a person is doing with an object. E.g. true: “boat is ridden by person”, “person ride boat”; also asked: “boat is boarded by person”, “boat is exited by person”, “boat is launched by person”, “boat is rowed by person”…
  • Negation (1858 photos, 2.0 descriptions per photo): what an object is not, or doesn't have. E.g. true: “computer without screen on”; also asked: “computer with screen on”
  • Celebrity (2244 photos, every name in the subset): famous people, by name. E.g. true: “elon musk”; also asked: “barack obama”, “bill gates”, “dwayne johnson”, “jeff bezos”…
  • Logo (1935 photos, every name in the subset): brand logos. E.g. true: “benz logo”; also asked: “amazon logo”, “apple logo”, “coca-cola logo”, “disney logo”…
  • Landmark (1533 photos, every name in the subset): famous buildings and monuments. E.g. true: “big ben”; also asked: “arc de triomphe”, “eiffel tower”, “empire building”, “mount fuji”…

Average recall (AR, %), the official COCO metric: per description, the share of its ground-truth boxes found with that description, averaged over IoU thresholds 0.50–0.95; then averaged over the descriptions in a subset, and over the 8 subsets. Before scoring, the official NMS keeps one box per ground-truth object whatever its label (here the one written first), so labelling an object with several descriptions doesn't help. Even the ground truth scores a little below 100: where two true boxes of different descriptions overlap, that NMS keeps only one. AP: the official NMS-AP, but every box has the same confidence, so it ranks boxes in photo order and is not comparable to a detector's AP. Precision@0.5: the share of all boxes drawn that match a true box with the right description at IoU 0.5. Time per question: from sending a question to receiving the whole answer (reasoning included), with questions sent one at a time and nothing else on the GPUs. Every image is sent as new, so the server can't reuse work from earlier questions on the same image, as for a robot whose next question comes with a new camera frame. Output tokens: median per question, reasoning included. Unusable answers: cut off at the token limit, unparsable, or failed (hover for which); they count as wrong.
