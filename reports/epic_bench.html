EPIC-Bench

Fine-grained visual grounding for robots: 6661 questions in 23 task types (paper), scored with the official evaluation. The model answers with boxes (points for paths), scored against ground-truth masks.

What each category tests

  • Target localization (4410 questions, 14 types): box every object matching a description and count them; types differ by what the description uses (category, color, material, part, spatial relation, orientation, spoken request, ...). E.g. “Balloon”
  • Navigation (1245 questions): box the walkable ground; draw a path of points to a marked area (from the camera, or between two areas); find an area marked in one view in a second view and count it.
  • Manipulation (1006 questions): box the part of a marked object to act on for a task (affordance); box and count the objects touching a marked object (or all / any of several); box the region described for placing an object and say whether it fits.

Each question scores 0–100. Boxes: IoU between the union of the answer's boxes and the union of the ground-truth masks (an empty answer is right only if there is no target). Count: exact match when the number matters (as in “two cups”), otherwise partial credit for being close; it weighs 10–50% of the question (30–50% unless the description states the count), 50% in visual matching. Path: points near the start and target areas, segments on the walkable path, moving away from the start and toward the target, evenly spaced.

Mean score per question (0–100). Overall is the official headline: the mean over all 6661 questions, so target localization (4410 questions) weighs 66% of it. Boxes can't reach 100: a mask is rarely a rectangle. Whole image as one box: one box over the whole image, one object, “fits”, and for paths a straight line from the bottom center up to the image center; it shows what an answer that ignores the question scores. Time per question: from sending a question to receiving the whole answer (reasoning included), with questions sent one at a time and nothing else on the GPUs. Every image is sent as new, so the server can't reuse work from earlier questions on the same image, as for a robot whose next question comes with a new camera frame. Output tokens: median per question, reasoning included. Unusable answers: cut off at the token limit, unparsable, or failed (hover for which); they count as wrong.
